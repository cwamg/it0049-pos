# IT0049 Point-of-Sale System

This is a basic Point-of-Sale website created with CodeIgniter 4 for Web System Technologies.

In TFA1, the customer and user records came from static PHP arrays. For TFA2, the application was updated to retrieve the records from a MySQL database using CodeIgniter Models and the `findAll()` method.

## Pages

- `/` – Landing page
- `/about` – About page
- `/customers` – Customer Accounts
- `/users` – User Accounts

## Technologies Used

- PHP 8.2
- CodeIgniter 4
- MySQL
- Composer
- XAMPP
- HTML and CSS
